# Animation Video

Drop your looping animation video here as:


animation.mp4


**Specs:**
- Format: MP4 (H.264) — widest browser support
- Duration: ~4 seconds, seamlessly looping
- Resolution: 512×512 or 800×800 (square, character centred)
- Frame rate: 24–30 fps
- Size target: under 2 MB
- Style: Character animation with highlighted muscle groups

The ExerciseMediaV2 component will automatically detect and play this video.
If no video is present, it falls back to the static exercise image.
